# 选手立绘 / 头像

把图片按选手 `id` 命名放进这个文件夹，重启服务就会显示（支持 png / webp / jpg / gif）：

| 文件名 | 选手 | 形象 |
|---|---|---|
| `deepseek.png` | DeepSeek | 蓝发鲸鱼女仆 |
| `qwen.png` | 通义千问 | 紫发古风折扇 |
| `mimo.png` | MiMo | 白橙双马尾少女 |
| `doubao.png` | 豆包 | 黄色圆滚滚 |
| `claude.png` | Claude | 橙色像素机器人 |

- 一张图同时用于牌桌上的大立绘和排行榜、战况里的圆形小头像（小头像取图片上部）。
- 最好用**透明背景的半身抠图**，并在 `config.json` 里给这个选手加 `"cutout": true`，效果和设计稿一样。
- 不是抠图（方形带背景）也可以，不加 `cutout`，大立绘边缘会自动渐隐。
- 没放图片的选手显示自动生成的六边形徽章。
- 也可以在配置里写 `"avatar": "https://..."` 用网络图片。
